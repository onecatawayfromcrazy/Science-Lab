Science Lab – Grade 5 CAPS NST
README | Noah's Interactive Study App | November 2026

Science Lab is an interactive study app designed to help Noah prepare for his Grade 5 Natural Sciences and Technology (NST) examination.

The app follows the same design and reward system as History Quest. Its learning material is based on the school's examination guide, 42 pages of classroom modules, previous practice papers and memorandums.

⭐ How the star rewards work
Science Lab encourages active learning rather than simply reading and memorising text.

Noah earns:
- 5 stars for each lesson memory answer he has memorised.
- 2 stars for each word-bank definition he knows.
There are 484 study stars available.

The idea is to read the question, try to answer without looking, reveal the explanation and only mark it as memorised once the answer is understood.

Stars are awarded once per item, not every time it is opened.
🧪 How to use the app
1. Lessons: Start with the lessons to understand each topic. Explore interactive diagrams, reveal explanations and complete memory challenges.

2. Flashcards: Read the question, think of the answer, then flip the card to check. Mark cards as learnt once they can be answered independently.

3. Quiz Missions: Choose a topic and number of questions. The app provides feedback and explanations after answers. Incorrectly answered questions can be practised again using the Mistake Mission.

4. Practice Papers: Complete written exam-style questions, reveal the model answers and use the marking checklist to award marks.

5. Word Bank: Tap a science term to reveal its meaning. Search for specific words and earn stars for memorised definitions.
🌍 Interactive spinning globe
The Planet Earth lesson includes a rotating globe to help explain Earth's movement.

Tap Rotate Earth ½ turn to watch the continents move around Earth's tilted axis. Tap again to complete a full turn.

The model demonstrates how different parts of Earth face towards or away from the Sun, producing day and night.
💾 Saving progress
Science Lab saves progress locally in the browser, including:
- Learner name
- Completed lessons
- Earned stars
- Flashcard progress
- Quiz history
- Practice-paper responses
No account or login is required.

Important: Progress is specific to the browser and device being used. It does not automatically transfer between devices. Clearing browser data, using private browsing or moving to another version of the app may affect saved progress.
📱 Opening Science Lab
Science Lab is provided as a standalone HTML file.

It can be opened in Safari, Chrome, Edge or Firefox on a computer or compatible tablet.

The app works offline once opened locally, and it does not require an installation or subscription.

On an iPad, open the file in a full browser where possible, rather than relying on a basic document preview.
🔒 Privacy and sharing
Science Lab does not require Noah to create an online account.

The HTML file can be shared directly with family or friends. Each learner can use their own copy and earn their own stars.

If the app is uploaded to an HTML-hosting service, its accessibility will depend on that service's sharing and privacy settings. An unlisted link is not necessarily private or password-protected.
🔧 Troubleshooting
The buttons aren't working: Open the HTML file in a full browser with JavaScript enabled.

The globe isn't turning: Make sure you're using the latest Globe Fixed edition and tap the rotation button.

Stars or progress disappeared: Check whether you're using the same browser, device and file location. Also check whether browser data was cleared.

Read Aloud isn't working: Check the device volume and whether the browser supports text-to-speech.
🎯 Study tips
For the best results, Noah should work through a lesson before attempting its quiz. Encourage him to explain answers in his own words, especially when questions ask him to describe, explain, predict, compare or justify.

The practice exams should be completed without looking at the answers first. Afterwards, use the marking guides to identify topics that need more revision.

Science Lab is a revision resource, not an official school examination. Where there are differences, the school's instructions and teacher corrections should take priority.
